# EIRA Inventor Holographic Lab V5

General invention-to-engineering-to-3D extension. Evidence -> engineering IR -> science/math preflight -> constructible geometry -> motion -> Blender -> GLB. Unknown complex geometry is never silently reduced to a cube.

Truth classes: observed, stated, calculated, inferred, assumed, hypothesized, unresolved.

Geometry: mesh, curves, extrude, revolve, sweep, loft, surfaces, instances, booleans, compounds.

Motion: fixed, revolute, continuous, oscillating, prismatic, keyframed, coupled.

Tests: `python3 tests/regression_300.py`, `python3 tests/test_failures.py`, `python3 tests/test_reference_greenhouse.py`.
