# OMNIVENOM

`omnivenom_mesh_ai` is only the connective symbiote. It contains no language model and does not create a third brain.

It crawls an existing Eira LIVE tree without importing discovered code, registers directories/files/modules/symbols/manifests/capabilities/dependencies as findable persistent nodes, creates relationship edges, preserves missing internal references as unresolved nodes, reconnects recovered modules, records duplicate/semantic lineage, and registers the existing new brain as dominant with the existing old brain as tandem/advisory tissue.

`TandemBridge` has one outward return value: the dominant brain's result. Legacy output can be supplied to the dominant brain only as advisory evidence.

The mesh does not blindly move or rewrite original files. "Morph" means the persisted graph can correct identity, aliases, canonical relationships, lineage and recovered locations while preserving the real LIVE bytes. Physical rewrites remain outside discovery authority.
